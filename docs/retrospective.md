# Retrospective

## What would I do differently?

I would set up environment variables properly from the first day.
I would avoid hardcoded fallback values for secrets.
This would make the project safer and easier to configure.
I would also document the setup clearly for anyone working on it.

## What took the most time?

The OTA model update work took the most time.
It involved several pieces that needed to work together.
Testing and fixing the failures took longer than I expected.
I learned to break complex work into smaller steps and test them early.

## What would I do with two more weeks?

I would automate the model retraining process.
I would add more tests for the web app.
I would test the app on iOS and improve monitoring.
These changes would make the project more reliable and easier to maintain.
